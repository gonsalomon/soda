# SODA onboarding
At the moment this repo was created, our company was looking for a partnership with Soda -awesome tool-, a Data Quality tool to run checks on data to assure proper data health. This assurance in turn gives users confidence on how trustable the information on a dashboard will be- which, while forming Data Analysts, was one of the main concerns from our employer company. 

## What we learnt
This tool has an awesome core functionality (a set of checks written in YAML) with a huge amount of integrations, ranging from communication (MS Teams, Slack, Jira, ServiceNow, Webhook), into -one of its biggest strengths, we learnt- catalogs and governance tools (Alation, Atlan, Collibra, data.world, Metaphor, Purview), to some BI tools (Sigma), and CI/CD (GitHub Actions, dbt, Airflow).

All in all, it was great to bundle together a bunch of distinct software, while learning how to integrate tools and making things in the cloud cooperate for a common purpose.
